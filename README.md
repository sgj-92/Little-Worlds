# Little Worlds

A private, AI-powered storytelling app that turns a child's imagination into narrated storybooks.

> **Milestone 1 — UX prototype.** Everything runs locally on mock adapters. There are no AI
> providers, accounts or credentials yet; simulated behaviour is labelled in the UI.

```bash
npm install
npm run dev          # http://localhost:5173
npm run check        # typecheck, lint, unit tests, production build
npm run test:e2e     # Playwright journeys on phone and tablet viewports
```
